# 掐指一算

用小六壬掐指一算的小網頁。心裡想一件事，按住按鈕起課，大拇指會從月份數到日子，再數到時辰，停在哪一格就是答案。

線上玩：https://iammay22.github.io/pinch-of-fate/

## 玩法

1. 寫下想問的事（不寫也可以），選一個方向：感情、工作學業、找東西或其他
2. 選要讓它自己掐，還是自己點手掌一格一格掐
3. 按住「按住起課」，心裡默念那件事
4. 看結果，可以做成分享卡或複製結果傳給朋友

時間預設抓現在的農曆月、日和時辰，也可以按「改時間」自己選。晚上十一點以後算隔天的子時。

## 檔案

- `index.html`：整個網頁，CSS、JS 和六張手勢圖都在裡面
- `apps-script/Code.gs`：後台的資料接收程式，貼在「掐指一算｜數據後台」試算表的 Apps Script

## 後台

網頁每次有人進站或按按鈕，會送一筆事件到 Apps Script，寫進試算表的 events 分頁。數據總覽、每日趨勢、遊玩分析三個分頁都是公式，有新資料就會自動更新。事件種類和欄位定義寫在試算表的「說明」分頁。

`index.html` 裡的 `ENDPOINT` 填 Apps Script 的部署網址，留空就不會送資料。問題內容不會送出，只記有沒有寫。
